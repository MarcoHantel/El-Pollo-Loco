El Pollo Loco
A 2D jump-and-run browser game built with JavaScript.

About the Game

El Pollo Loco is a classic side-scrolling platformer developed over the course of 5 weeks.
You play as Pepe, a Mexican character who must survive in a hostile environment filled with crazy chickens.

Your mission:
Collect coins and bottles
Fight enemies using your collected bottles
Defeat the final boss a giant, aggressive chicken

Gameplay Features
Classic 2D jump-and-run mechanics

Collectible items:
Coins and Bottles (used as weapons)

Enemies:
Yellow chickens
Brown chickens

Boss fight:
Giant chicken as final boss

Combat system:
Throw bottles at enemies
Jump on enemies to defeat them

Technologies Used
JavaScript (ES6)
HTML5
CSS3
Object-Oriented Programming (OOP)
Canvas API

How to Run the Project
Clone the repository:
git clone https://github.com/YOUR_USERNAME/el-pollo-loco.git
Open the project folder:
cd el-pollo-loco
Open index.html in your browser
